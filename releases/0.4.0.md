## New: GitBook courses to offline EPUB

Paste a public GitBook course home URL to download its chapters and images into one EPUB with a hierarchical table of contents.

- New **Tools > Import EPUB from GitBook URL...** command, with English and Chinese labels.
- Download progress, cancellation, retries, and explicit failure reporting.
- Images are embedded for offline reading.
- The EPUB is stored as a managed attachment in the collection selected when the import window opens.
- Existing TXT/Markdown attachment conversion remains available and keeps the original files.

## Install

Download **txt-md-to-epub-for-zotero-0.4.0.xpi** from the assets below. In Zotero, open **Tools > Plugins**, choose **Install Plugin From File...** from the gear menu, select the XPI, and restart Zotero. This updates the existing plugin; a separate installation is not needed.

## Compatibility and verification

- Installation compatibility checks pass for Zotero 9.0.5 and 10.0.3.
- The new importer was tested end-to-end on Zotero 10.0.3 for Windows; it has not yet been runtime-tested on 9.0.5.
- The MIT6.S081 Chinese course test produced 180 chapter pages and 819 embedded images.
- Generated XML and 2,185 internal resource references passed validation.
- Collection placement, cancellation, image failure handling, and HTML sanitization were checked.

## Scope

Supports public GitBook sites exposing a `llms.txt` chapter index and Markdown endpoints. This is not a general website crawler. Login-protected content, video, SVG images, interactive content, and rendered math are not supported. PNG, JPEG, GIF, and WebP images are supported; WebP is converted to PNG.

Automatic plugin updates are not configured yet. Install this XPI manually to update.
